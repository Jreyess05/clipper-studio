# Clipper Studio

Long videos → ready-to-post vertical clips for TikTok, Reels and Shorts, made on your own PC.

**Get it on Whop: [whop.com/getclipperstudio](https://whop.com/getclipperstudio)**. The free trial makes 3 clips, no card needed.

This repository only hosts the Windows installer. There is no source code here.

## Install

1. Download **[ClipperStudio-Setup.exe](https://github.com/Jreyess05/clipper-studio/releases/latest/download/ClipperStudio-Setup.exe)**. If your browser asks, choose **Keep**.
2. Open it and click **Install**. If Windows says "Windows protected your PC", click **More info** → **Run anyway**. It shows up because the app is new.
3. The app opens by itself in your browser. Click **Try it free**, or paste the license key from your Whop purchase.

Next time, open it from the **Clipper Studio** icon on your desktop or in the Start menu.

**Requirements:** Windows 10 or 11 (64-bit), 8 GB of RAM (16 GB recommended), 5 GB of free disk space.
